# Oropesa Bus Data

Данные для Android-приложения автобусной карты Оропесы.

## Структура

- `config.json` — общие настройки и raw-ссылки GitHub.
- `data/route.json` — линия маршрута.
- `data/stops.json` — остановки, иконки, карточки и привязка к точкам маршрута.
- `data/schedule.json` — расписание: шаблон круга + времена стартов.
- `data/categories.json` — категории карточек и иконок.
- `data/buses.json` — автобусы.
- `data/objects.json` — здания и объекты.
- `data/calendar.json` — будни, выходные и праздники.
- `media/icons/` — SVG-иконки.
- `media/cards/` — JPG-картинки карточек.

## Важно

Маршрут и движение автобуса берутся из `route.json`.
Остановки привязаны к маршруту через `routeAnchor.pointIndex`.
Расписание хранит только известные контрольные времена, а промежуточное движение приложение рассчитывает само.
