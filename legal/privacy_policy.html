Política de privacidad

Oropesa del Mar autobús urbano

Última actualización: 19 de junio de 2026

Español

1. Responsable y aplicación

Esta Política de privacidad se aplica a la aplicación Oropesa del Mar autobús urbano, una aplicación informativa para consultar el mapa, paradas, horarios y datos relacionados con el autobús urbano de Oropesa del Mar.

Desarrollador/responsable: tvitaly / Vitalii Titarenko.

Página pública del proyecto: https://github.com/tvitaly/orpesadata

2. Datos personales que recoge el desarrollador

La aplicación no requiere registro, no crea cuentas de usuario y no solicita nombre, correo electrónico, teléfono, documentos de identidad, datos bancarios ni otros datos personales directamente identificativos.

El desarrollador no vende datos personales y no utiliza la aplicación para publicidad personalizada, analítica comercial o seguimiento de usuarios.

3. Uso de la ubicación

La aplicación puede solicitar permiso de ubicación del dispositivo para mostrar la posición aproximada o precisa del usuario en el mapa y para centrar el mapa mediante el botón de navegación.

La ubicación se utiliza para funciones visibles dentro de la aplicación. La aplicación no requiere iniciar sesión y no envía intencionadamente la ubicación del usuario al desarrollador para crear perfiles personales.

Si el usuario no concede el permiso de ubicación, la aplicación puede seguir mostrando el mapa, paradas, horarios e información general, pero no podrá mostrar la posición actual del usuario.

4. Conexión a Internet, mapa y datos técnicos

La aplicación utiliza conexión a Internet para cargar datos públicos del servicio, como archivos JSON, imágenes, iconos, política de actualización, manifiesto de caché y recursos de mapa.

Al cargar recursos externos, los proveedores técnicos de alojamiento, mapas o red pueden recibir información técnica normal de conexión, como dirección IP, tipo de navegador/WebView, hora de la solicitud y recurso solicitado. Esta información es necesaria para entregar el contenido solicitado y depende de los servicios externos usados para alojar o mostrar el mapa y los datos públicos.

5. Caché local

La aplicación puede guardar en el dispositivo una copia local de datos públicos, imágenes e iconos para mejorar la carga y reducir descargas repetidas. Esta caché no está destinada a guardar datos personales del usuario.

6. Compartición de datos

El desarrollador no vende datos personales ni comparte datos personales del usuario con fines publicitarios. Los datos públicos de la aplicación se alojan en servicios externos de publicación y descarga de archivos.

7. Seguridad y conservación

La aplicación intenta limitar el tratamiento de datos a lo necesario para mostrar el mapa, la ubicación local del usuario si se concede permiso, los horarios y la información pública del servicio.

Los datos públicos almacenados en caché pueden permanecer en el dispositivo hasta que el sistema, el usuario o la propia aplicación los eliminen o actualicen.

8. Menores

La aplicación es informativa y no está diseñada para recoger datos personales de menores. No incluye registro, mensajería, pagos ni funciones sociales.

9. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de la aplicación, los permisos utilizados o los servicios técnicos necesarios. La versión actual estará disponible en esta misma página.

10. Contacto

Para consultas relacionadas con esta política, puede utilizarse la información de contacto publicada en la ficha de Google Play de la aplicación o la página pública del proyecto indicada arriba.

English

This English section is provided for easier review.

1. Controller and app

This Privacy Policy applies to the Oropesa del Mar autobús urbano app, an informational app for viewing the map, stops, timetables and related public data for the urban bus service in Oropesa del Mar.

Developer/controller: tvitaly / Vitalii Titarenko.

Public project page: https://github.com/tvitaly/orpesadata

2. Personal data collected by the developer

The app does not require registration, does not create user accounts and does not ask for a name, email address, phone number, identity documents, bank details or other directly identifying personal data.

The developer does not sell personal data and does not use the app for personalized advertising, commercial analytics or user tracking.

3. Location use

The app may request device location permission to show the user's approximate or precise position on the map and to center the map using the navigation button.

Location is used for visible in-app features. The app does not require sign-in and does not intentionally send the user's location to the developer to create personal profiles.

If the user does not grant location permission, the app can still show the map, stops, timetables and general information, but it will not be able to show the user's current position.

4. Internet connection, map and technical data

The app uses an Internet connection to load public service data, such as JSON files, images, icons, update policy, cache manifest and map resources.

When external resources are loaded, hosting, map or network providers may receive standard technical connection information, such as IP address, browser/WebView type, request time and requested resource. This information is necessary to deliver the requested content and depends on the external services used to host or display the map and public data.

5. Local cache

The app may store a local copy of public data, images and icons on the device to improve loading and reduce repeated downloads. This cache is not intended to store the user's personal data.

6. Data sharing

The developer does not sell personal data and does not share users' personal data for advertising purposes. Public app data is hosted on external services used for publishing and downloading files.

7. Security and retention

The app aims to limit data processing to what is necessary to display the map, the user's local position if permission is granted, timetables and public service information.

Public data stored in the cache may remain on the device until it is removed or updated by the system, the user or the app.

8. Children

The app is informational and is not designed to collect children's personal data. It does not include account registration, messaging, payments or social features.

9. Changes to this policy

This policy may be updated when the app's features, permissions or required technical services change. The current version will be available on this page.

10. Contact

For questions related to this policy, users may use the contact information published on the app's Google Play listing or the public project page linked above.
