Política de privacidad

Oropesa del Mar autobús urbano

Última actualización: 21 de junio de 2026

Español

1. Responsable y aplicación

Esta Política de privacidad se aplica a la aplicación Oropesa del Mar autobús urbano, una aplicación informativa para consultar el mapa, paradas, horarios y datos relacionados con el autobús urbano de Oropesa del Mar.

Desarrollador/responsable: tvitaly / Vitalii Titarenko.

Repositorio público del proyecto: https://github.com/tvitaly/orpesadata

Política de privacidad: https://tvitaly.github.io/orpesadata/privacy.html

Correo electrónico de contacto: orpesabus@gmail.com

2. Datos personales que recoge el desarrollador

La aplicación no requiere registro, no crea cuentas de usuario y no solicita nombre, correo electrónico, teléfono, dirección postal, documentos de identidad, datos bancarios ni otros datos personales directamente identificativos.

El desarrollador no vende datos personales y no utiliza la aplicación para publicidad personalizada, analítica comercial ni creación de perfiles comerciales de usuarios.

3. Uso de la ubicación

La aplicación puede solicitar permiso de ubicación del dispositivo al abrir la aplicación o al utilizar la función de ubicación.

La ubicación aproximada o precisa se utiliza únicamente para mostrar la posición actual del usuario en el mapa, centrar la vista y ayudar al usuario a orientarse respecto a la ruta y las paradas.

La aplicación no utiliza la ubicación para publicidad, no vende datos de ubicación y no crea perfiles comerciales de los usuarios a partir de su ubicación.

La aplicación no solicita acceso a la ubicación en segundo plano. La ubicación se usa solo mientras la aplicación está abierta o visible para el usuario.

Si el usuario no concede el permiso de ubicación, la aplicación puede seguir mostrando el mapa, las paradas, los horarios y la información general, pero no podrá mostrar la posición actual del usuario.

4. Conexión a Internet, mapa y datos técnicos

La aplicación utiliza conexión a Internet para cargar datos públicos necesarios para su funcionamiento, como archivos JSON, ruta, paradas, horarios, iconos, imágenes, estilos, política de actualización, manifiesto de caché y recursos de mapa.

Al cargar recursos externos, los proveedores técnicos de alojamiento, mapas o red pueden recibir información técnica normal de conexión, como dirección IP, tipo de navegador/WebView, hora de la solicitud y recurso solicitado. Esta información es necesaria para entregar el contenido solicitado y depende de los servicios externos usados para alojar o mostrar el mapa y los datos públicos.

5. Caché local

La aplicación puede guardar en el dispositivo una copia local de datos públicos, imágenes, iconos y otros recursos necesarios para mejorar la carga, reducir descargas repetidas y permitir el funcionamiento con conexión limitada o sin conexión.

Esta caché no está destinada a guardar datos personales del usuario. Para eliminar la caché local, el usuario puede borrar los datos de la aplicación desde los ajustes del dispositivo o desinstalar la aplicación.

6. Compartición de datos

El desarrollador no vende datos personales ni comparte datos personales del usuario con fines publicitarios o de marketing.

Los datos públicos de la aplicación se alojan en servicios externos de publicación y descarga de archivos. Los servicios técnicos externos pueden tratar datos técnicos de conexión necesarios para entregar los recursos solicitados por el dispositivo.

7. Seguridad y conservación

La aplicación intenta limitar el tratamiento de datos a lo necesario para mostrar el mapa, la posición local del usuario si se concede permiso, los horarios y la información pública del servicio.

Los datos públicos almacenados en caché pueden permanecer en el dispositivo hasta que el sistema, el usuario o la propia aplicación los eliminen o actualicen.

8. Menores

La aplicación es informativa y no está diseñada para recoger datos personales de menores. No incluye registro, mensajería, pagos ni funciones sociales.

9. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de la aplicación, los permisos utilizados o los servicios técnicos necesarios. La versión actual estará disponible en esta misma página.

10. Contacto

Para consultas relacionadas con esta política o con la aplicación, puede escribir a: orpesabus@gmail.com.

This English section is provided for easier review.

1. Controller and app

This Privacy Policy applies to the Oropesa del Mar autobús urbano app, an informational app for viewing the map, stops, timetables and related public data for the urban bus service in Oropesa del Mar.

Developer/controller: tvitaly / Vitalii Titarenko.

Public project repository: https://github.com/tvitaly/orpesadata

Privacy Policy: https://tvitaly.github.io/orpesadata/privacy.html

Contact email: orpesabus@gmail.com

2. Personal data collected by the developer

The app does not require registration, does not create user accounts and does not ask for a name, email address, phone number, postal address, identity documents, bank details or other directly identifying personal data.

The developer does not sell personal data and does not use the app for personalized advertising, commercial analytics or commercial user profiling.

3. Location use

The app may request device location permission when the app is opened or when the location function is used.

Approximate or precise location is used only to show the user's current position on the map, center the map view and help the user orient themselves in relation to the route and stops.

The app does not use location for advertising, does not sell location data and does not create commercial user profiles based on location.

The app does not request background location access. Location is used only while the app is open or visible to the user.

If the user does not grant location permission, the app can still show the map, stops, timetables and general information, but it will not be able to show the user's current position.

4. Internet connection, map and technical data

The app uses an Internet connection to load public data needed for its operation, such as JSON files, route, stops, timetables, icons, images, styles, update policy, cache manifest and map resources.

When external resources are loaded, hosting, map or network providers may receive standard technical connection information, such as IP address, browser/WebView type, request time and requested resource. This information is necessary to deliver the requested content and depends on the external services used to host or display the map and public data.

5. Local cache

The app may store a local copy of public data, images, icons and other resources on the device to improve loading, reduce repeated downloads and allow operation with limited or no connectivity.

This cache is not intended to store the user's personal data. To remove the local cache, the user can clear the app data in the device settings or uninstall the app.

6. Data sharing

The developer does not sell personal data and does not share users' personal data for advertising or marketing purposes.

Public app data is hosted on external services used for publishing and downloading files. External technical services may process technical connection data needed to deliver the resources requested by the device.

7. Security and retention

The app aims to limit data processing to what is necessary to display the map, the user's local position if permission is granted, timetables and public service information.

Public data stored in the cache may remain on the device until it is removed or updated by the system, the user or the app.

8. Children

The app is informational and is not designed to collect children's personal data. It does not include account registration, messaging, payments or social features.

9. Changes to this policy

This policy may be updated when the app's features, permissions or required technical services change. The current version will be available on this page.

10. Contact

For questions related to this policy or the app, users may write to: orpesabus@gmail.com.
